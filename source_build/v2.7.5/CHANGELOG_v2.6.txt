PUMA STOCK PRO v2.6.0

응답없음 2차 긴급 수정

GUI 메인스레드
- v2.5는 REST 통신만 백그라운드로 보냈고, 데이터 수신 직후
  스윙/중장기/단타/수박/확률/박스 계산을 다시 GUI 스레드에서 실행하는 문제가 남아 있었음
- v2.6은 CPU 분석까지 전부 별도 QThread로 이동
- 메인 UI 스레드는 결과를 받아 화면에 그리는 작업만 수행
- 분석 중 창 이동, 스크롤, 탭 전환, 버튼 입력이 멈추지 않도록 구조 변경

백그라운드 분석 대상
- 역매공파/스윙 분석
- 밥그릇3번/중장기 분석
- 5분봉 단타 분석
- 공통 수급→돌파→눌림→재돌파 경로
- 공구리 박스 탐색
- 수박근사
- 동일단계 과거확률/신뢰구간
- 날짜별 단타 재분석

중복 작업 방지
- 종목을 연속 클릭해도 CPU 분석 작업을 무한히 쌓지 않음
- 진행 중이면 가장 최신 요청 하나만 대기시켜 이어서 실행
- 오래된 종목 분석 결과는 화면에 적용하지 않고 폐기
- 통합트레이딩 분석 결과를 단타 상세탭에서 재사용

박스 탐색 추가 고속화
- 거래량강도 300% 후보봉 선필터 유지
- 박스 기간 전수검사 대신 coarse scan -> 상위 후보 주변 refine 2단계 탐색
- 지지/저항/왕복/기울기/방향성 판정 기준은 유지
- 동일 캔들+설정 분석 캐시 유지

정확도
- 돌파/눌림/재돌파 판단 기준을 속도 때문에 낮추지 않음
- 기존 화살표/수박/확률/공구리 표시 유지
