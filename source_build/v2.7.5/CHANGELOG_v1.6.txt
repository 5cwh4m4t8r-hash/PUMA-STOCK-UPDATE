PUMA STOCK PRO v1.6.0

PUMA 수박근사
- 주식단테의 비공개 원본 수식이라고 주장하지 않는 독립 근사 모델
- 공개 강의/차트에서 반복 관찰되는 장기이평 수렴, 224EMA 돌파/안착, 눌림,
  거래량 확장/안정, 사용자 화살표 결합을 1~3단계로 수치화
- 기존 단순 초록/빨강 바가 아니라 실제 수박 모양의 원형 마커로 표시
- 1단: 장기이평 수렴 + 224EMA 근접
- 2단: 224EMA 최근 돌파 + 위 안착/눌림
- 3단: 2단 조건 + 거래량/화살표 강화
- 차트와 분석 상세에 'PUMA 수박근사'로 명확히 표기

확률/진입 판단
- 과거 동일계열 신호를 대상으로 TP-before-SL 실제 적중률 계산
- 표본수와 Wilson 95% 구간 표시
- 표본 부족이면 임의 확률을 만들지 않고 '판단 유보'
- 현재 전략 점수 + 현재 신호 활성 + 과거 적중률을 결합해
  '진입 적합도 높음 / 조건부 진입 검토 / 관망 우세 / 판단 유보' 표시
- 확률 기준과 TP/SL/평가기간을 함께 표시

마우스 휠 전수 점검
- 모든 일반 콤보박스를 NoWheelComboBox로 교체
- 숫자 직접입력/드롭다운 NumericComboBox 휠 차단
- 시간 드롭다운 TimeComboBox 휠 차단
- 날짜 NoWheelDateEdit 휠 차단
- QSpinBox/QDoubleSpinBox/QTimeEdit/QDateEdit 직접 사용 없음
- 차트의 마우스 휠 확대/축소만 의도적으로 유지
