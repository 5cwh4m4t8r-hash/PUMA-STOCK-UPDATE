PUMA STOCK PRO v1.0.0

UI 전면 재검토/개편
- 메인 통합 트레이딩 오른쪽을 분석/역매공파 설정/주문/자동매매 소형 탭으로 재배치
- 작은 해상도에서도 버튼과 입력창 높이가 눌려 사라지지 않도록 재구성
- 조건검색/차트/우측패널 분할 비율을 화면 해상도에 맞춰 자동 계산
- 사용자가 조절한 주요 분할 비율을 다음 실행에도 유지
- 역매공파 별도 중복 화면은 생성하지 않고 메인 화면에 완전 통합
- 역매공파 매집/공구리/파란점선 설정을 메인에서 수정 가능
- 역매공파 설정을 config/swing.json에 영구 저장

단타 분석 화면 개편
- 상단 차트/판정과 하단 설정을 세로 분할 가능
- 하단 설정을 분석 기준/주문·리스크/매도조건 3개 탭으로 변경
- 5분봉 기준을 고정해 화면 설정과 실제 분석 주기 불일치 제거
- 패턴 점수와 검색시간 조건 분리: 장 마감 후에도 패턴 강도 복기 가능
- PUMA 기준선/EMA/거래량/돌파/눌림 세부 판정표 유지
- 차트에 현재 표시 중인 EMA/파란점선/PUMA 기준선 색상 범례 추가

기타
- 잔고·로그 화면을 세로 분할형으로 변경
- 고급 주문 화면을 가변 분할형으로 변경
- 키움 설정 화면을 스크롤 안전 구조로 변경
- 오래된 v0.3 안내문 제거
