PUMA STOCK PRO v2.7.0 — 차트/분석 속도 최적화

- 선택한 차트의 첫 페이지를 받으면 캔들을 먼저 표시합니다.
- 보이는 전략부터 분석하여 결과를 단계적으로 표시합니다.
- 일봉 8페이지/분봉 4페이지의 전체 이력은 뒤에서 계속 받습니다.
- 최근 12개 화면의 완성 분석을 재사용하고, 조회 시각을 표시합니다.
- 2초 이내 완료 데이터는 재사용하며 이후 클릭 또는 새로고침은 최신 자료를 조회합니다.
- 조건검색에서 계산한 종목은 그 결과를 미리 준비하여 클릭 시 재사용합니다.
- 종목/설정/날짜/TP·SL/연결 변경을 구분하여 결과가 섞이지 않게 합니다.
- 이전 클릭의 남은 조회·계산을 취소하며 대기 요청은 최신 요청만 유지합니다.
- 같은 원본 자료는 재계산하지 않고, 과거 봉 수정도 캐시 무효화에 반영합니다.
- 박스 후보 중복 평가와 느린 평균 계산을 줄였습니다. 판정 임계값은 유지합니다.
- 종목명 조회 및 구간 분석도 화면 스레드 밖에서 처리합니다.
- 과거 데이터 추가 시 최신 위치 또는 보고 있던 날짜를 유지합니다.
- 종료 시 작업 스레드가 안전하게 정리될 때까지 화면 이벤트를 처리합니다.

적용: 프로그램의 업데이트 탭 → 업데이트 확인 → 업데이트 적용 → 재실행

검증: 합성 시세/지연을 사용한 44개 테스트, v2.6 판정/시계열 비교 4종 데이터셋.
실제 키움 계정 접속·주문 또는 사용자 Windows PC 실측은 수행하지 않았습니다.
첫 조회는 API 통신 시간이 필요하며, 저장된 결과는 표시된 조회 시각의 자료입니다.


[기존 사용 설명]
PUMA STOCK PRO v0.6
===================

[이번 업데이트 핵심]
1. 영웅문형 과거 차트 탐색
   - 마우스 휠: 확대/축소
   - 차트 좌우 드래그: 과거/최신 이동
   - 최신 / 전체보기 / 과거 60봉 이동 버튼
   - '과거 데이터 +5페이지'로 키움 일봉 추가 조회(최대 30페이지)
   - 일봉 ↔ 5분봉을 같은 종목 화면에서 전환

2. 원하는 과거 구간 분석
   - 시작일/종료일 직접 지정
   - 현재 화면에 보이는 구간 분석
   - 선택 구간은 차트에 음영으로 표시
   - 선택한 시점까지의 장기 이평/매집 이력을 포함해 역매공파와 밥그릇3번을 다시 판정

3. 단타 + 스윙 + 중장기 한 화면 통합
   조건검색 종목을 클릭하면 '종목 분석 · 매매' 화면에서 동시에 표시:
   - 오돌이 DAY: 5분봉 아침단타
   - 역매공파 SWING: 장기 역배열 → 매집봉/구간 → 공구리 → 파란점선
   - 밥그릇 3번 LONG: 장기간 224EMA 아래 → 224EMA 돌파/안착 → 눌림·지지

4. 밥그릇 3번 엔진 추가
   - EMA는 지수이평 기준
   - 224EMA 아래 장기 체류
   - 224EMA 상향 돌파
   - 돌파 후 위에서 안착
   - 224EMA 부근 눌림/지지
   - 수박/화살표는 최종식 입력 전까지 '대기'로 표시

5. 기존 기능 유지
   - 키움 REST API 모의/실전 연결
   - 영웅문4 [0150] 저장 조건검색 연동
   - 종목코드 + 종목명 표시
   - 수동 시장가/지정가/스톱지정가 주문
   - 선택 종목 자동매매
   - 익절/손절/트레일링스탑
   - 실전 LIVE 이중 잠금
   - 기존 보유주식 자동청산 보호

[설치]
처음 설치라면:
1) ZIP 완전 압축해제
2) 1_SETUP.bat 실행
3) 설치 완료 후 2_START_PUMA.vbs 실행

이미 v0.5를 쓰고 있다면 v0.6 폴더를 별도로 풀어 먼저 확인하는 것을 권장합니다.
config 폴더의 개인 전략값은 필요하면 이전 버전에서 복사할 수 있습니다.

[차트 사용]
- 조건검색 결과에서 종목 행 클릭
- '종목 분석 · 매매' 탭 자동 이동
- 일봉/5분봉 선택
- 휠로 확대/축소
- 마우스로 차트를 좌우 드래그
- 날짜 지정 후 '선택 날짜 분석'
- 또는 원하는 구간을 화면에 맞춘 뒤 '현재 보이는 구간 분석'

[역매공파 현재 기준]
- 장기 EMA 역배열: EMA112 < EMA224 < EMA448
- 매집봉: 고거래량 + (긴 윗꼬리 OR 장대음봉)
- 반복 시 매집구간 누적
- 공구리: 박스권 → 상단 돌파 → 기존 박스 위에서 버팀/안착
- 파란점선: shift(BBandsUp(26, 2.6), 26)
