PUMA STOCK PRO v2.8.0 — PUMA STOCK MOBILE 1차 연동

모바일 앱
- 아이폰/안드로이드에서 즉시 사용할 수 있는 설치형 모바일 웹앱(PWA)을 PC PUMA에 내장했습니다.
- 같은 Wi-Fi에서 PC의 모바일 연동 탭에 표시된 주소로 접속합니다.
- 6자리 연결코드 인증 후 Safari/Chrome 홈 화면 추가로 앱처럼 실행할 수 있습니다.
- 별도 App Key / App Secret을 휴대폰에 저장하거나 전송하지 않습니다.

연동 기능
- 조건검색 편입/이탈, 단타·스윙·밥그릇 분류 조회
- 모바일에서 종목을 선택하면 PC 통합 트레이딩 화면도 같은 종목으로 연동
- 일봉 / 5분봉 전환
- EMA112/224/448, 분홍/파랑/빨강/검정 화살표, 수박 표시
- 단타 DAY / 역매공파 SWING / 밥그릇3 LONG 분석 결과
- PUMA 관리 보유종목과 주문/신호 로그
- PC 허용 시 시장가/지정가/스톱지정가 수동 주문 요청

보안
- 모바일 주문은 매 실행 시 기본 OFF입니다.
- PC에서 모바일 주문 허용을 켜야 주문 API가 활성화됩니다.
- 실전 주문은 기존 PC LIVE 1차 잠금 + 모바일 LIVE ORDER 재확인을 둘 다 요구합니다.
- 모바일에서 자동매매 시작/중지는 허용하지 않습니다.
- HTTP 서버 스레드는 Qt 위젯을 직접 읽지 않고, 메인 스레드가 0.75초마다 경량 스냅샷을 발행합니다.

성능
- 최근 차트 데이터만 모바일로 전송하며, 메인 트레이딩 분석/차트 작업과 분리했습니다.
- N5095A 최적화와 기존 v2.7.7 화살표/SAR 수정은 그대로 유지합니다.
