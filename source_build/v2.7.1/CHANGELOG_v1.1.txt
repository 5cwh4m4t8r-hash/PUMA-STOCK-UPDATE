PUMA STOCK PRO v1.1.0

통합 트레이딩
- 조건검색 편입 종목을 PUMA 분석으로 단타/스윙/중장기/복합/관찰 분류
- 분류 셀에 단타·스윙·중장기 점수 요약 툴팁 표시
- 조건검색 편입 후 백그라운드 분석으로 분류 갱신
- 메인 하단에 단타 DAY + 역매공파 SWING + 밥그릇3번 LONG 3전략 요약 통합
- 메인 오른쪽 분석 탭에 단타 상세 요약 추가
- 메인 차트에서 일봉/5분봉 전환 가능
- 단타 상세분석 탭은 그대로 유지

수박형 하단 지표
- 차트 하단에 PUMA 수박형 짧은 초록/빨강 밴드 추가
- 5분봉과 일봉 모두 표시
- 타점 주변만 짧게 표시하고 바닥 전체를 연속 도색하지 않음
- 공개 화면 개념을 참고한 PUMA 해석형이며 특정 비공개/유료 수식을 복제하지 않음

입력 방식
- 숫자 스핀박스를 휠 없는 직접입력 + 드롭다운 화살표 방식으로 전환
- 마우스 휠로 숫자가 실수로 바뀌지 않음
- 드롭다운에서 자주 쓰는 값을 고르거나 직접 입력 가능
- 검색 시작/종료/청산 시각도 직접입력 + 드롭다운 방식으로 전환
- 날짜 입력도 마우스 휠 변경 차단
