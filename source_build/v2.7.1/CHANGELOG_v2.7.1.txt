PUMA STOCK PRO v2.7.1 — N5095A / 저전력 CPU 체감속도 최적화

- Intel Celeron N5095A를 Windows CPU 이름에서 자동 감지합니다.
- N5095A + RAM 12GB에서는 표시/분석/구간 캐시를 12/24/6으로 그대로 유지해 재계산을 줄입니다.
- N5095A는 CPU/렌더링만 저전력 프로필로 처리합니다.
- 선택 종목의 무거운 차트 조회는 저전력 CPU에서 동시에 1개만 실행합니다.
- 조건검색 후보 사전분석은 선택 종목 처리보다 뒤로 미루고 작업 사이에 0.9초 휴지 시간을 둡니다.
- 저전력 CPU에서는 첫 화면 차트 표시량을 90봉으로 조정합니다. 실제 분석에는 전체 수신 데이터를 그대로 사용합니다.
- 첫 차트 선표시 전에 전체 이력 revision 해시를 계산하지 않아 첫 페인트를 앞당깁니다.
- 조건검색 백그라운드 분류에서는 확률/백테스트 enrichment를 미루고 핵심 DAY/SWING/LONG 점수만 먼저 계산합니다.
- N5095A/Intel UHD에서는 차트 안티앨리어싱을 줄여 페인트 비용을 낮춥니다.
- 역매공파/매집봉/공구리/돌파·눌림·재돌파/밥그릇3번/확률/주문 로직의 판정 기준은 변경하지 않았습니다.

적용: 프로그램의 업데이트 탭 → 업데이트 확인 → 업데이트 적용 → 재실행
