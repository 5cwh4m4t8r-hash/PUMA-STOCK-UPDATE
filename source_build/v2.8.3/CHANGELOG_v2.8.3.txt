PUMA STOCK PRO v2.8.3 — 모바일 작동형 데모 내장

- 외부 raw.githack / htmlpreview 호스팅을 더 이상 사용하지 않습니다.
- PUMA 자체 모바일 서버가 /demo 경로에서 작동형 데모를 직접 제공합니다.
- 같은 Wi-Fi에서 PC PUMA의 '모바일 연동' 탭에 표시되는 '작동형 데모' 주소를 Safari로 열면 됩니다.
- 데모에는 홈 / 자동매매 / 조건검색 / 차트 / 잔고 / 설정 탭이 모두 있습니다.
- PUMA LIVE 최초 1회 잠금 해제, 자동매매 설정 변경, 자동매매 시작/중지,
  조건검색 후보 선택, 모의 자동매수, 보유 감시, 트레일링, 모의 자동매도를 직접 눌러 체험할 수 있습니다.
- /demo는 외부 인터넷 호스팅이 필요 없고 모바일 연결코드 인증도 요구하지 않습니다.
- /api/state 등 실제 PUMA 상태/주문 API는 기존 6자리 연결코드 인증을 그대로 유지합니다.
- 데모에서는 키움 주문을 절대 호출하지 않습니다.
