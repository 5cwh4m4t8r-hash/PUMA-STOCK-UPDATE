PUMA STOCK PRO v2.7.1 — 저사양 노트북 자동 최적화

- CPU 코어 수와 물리 메모리를 자동 감지해 성능 프로필을 선택합니다.
- 4GB급 RAM + 저전력/구형 4코어 환경은 very-low-power 프로필을 사용합니다.
- 분석 기준, 신호 임계값, 전체 과거 데이터 보존 방식은 변경하지 않습니다.
- 첫 차트 선표시 전에 수행되던 전체 이력 revision 해시 계산을 제거합니다.
- 저사양에서는 차트 안티앨리어싱과 조밀한 선 렌더링을 자동 경량화합니다.
- 전체 데이터는 그대로 유지하며 초기 화면에 보이는 봉 수만 줄여 첫 페인트 비용을 낮춥니다.
- 조건검색 백그라운드 분류는 핵심 DAY/SWING/LONG 점수만 계산합니다.
- 확률/진입판단/상세 백테스트는 실제 선택 종목에 CPU를 우선 배정해 계산합니다.
- 백그라운드 후보 분석 사이에 휴지 시간을 늘려 UI와 선택 종목 분석이 먼저 처리됩니다.
- 표시/분석/구간 캐시 크기를 메모리에 맞게 자동 축소해 4GB 환경의 스왑을 줄입니다.
- 콤보박스/툴팁 애니메이션을 저사양에서 비활성화합니다.
- 환경변수 PUMA_PERFORMANCE_MODE=normal|low|very_low 로 프로필을 강제할 수 있습니다.

목표: 네트워크/키움 API 대기시간을 제외한 프로그램 자체 지연을 최소화.
