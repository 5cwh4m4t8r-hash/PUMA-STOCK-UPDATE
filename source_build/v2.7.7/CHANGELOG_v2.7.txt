PUMA STOCK PRO v2.7.0 — 차트/분석 속도 최적화

- 선택한 차트의 첫 페이지를 받으면 캔들을 먼저 표시합니다.
- 보이는 전략부터 분석하여 결과를 단계적으로 표시합니다.
- 일봉 8페이지/분봉 4페이지의 전체 이력은 뒤에서 계속 받습니다.
- 최근 12개 화면의 완성 분석을 재사용하고, 조회 시각을 표시합니다.
- 2초 이내 완료 데이터는 재사용하며 이후 클릭 또는 새로고침은 최신 자료를 조회합니다.
- 조건검색에서 계산한 종목은 그 결과를 미리 준비하여 클릭 시 재사용합니다.
- 종목/설정/날짜/TP·SL/연결 변경을 구분하여 결과가 섞이지 않게 합니다.
- 이전 클릭의 남은 조회·계산을 취소하며 대기 요청은 최신 요청만 유지합니다.
- 같은 원본 자료는 재계산하지 않고, 과거 봉 수정도 캐시 무효화에 반영합니다.
- 박스 후보 중복 평가와 느린 평균 계산을 줄였습니다. 판정 임계값은 유지합니다.
- 종목명 조회 및 구간 분석도 화면 스레드 밖에서 처리합니다.
- 과거 데이터 추가 시 최신 위치 또는 보고 있던 날짜를 유지합니다.
- 종료 시 작업 스레드가 안전하게 정리될 때까지 화면 이벤트를 처리합니다.

적용: 프로그램의 업데이트 탭 → 업데이트 확인 → 업데이트 적용 → 재실행

검증: 합성 시세/지연을 사용한 44개 테스트, v2.6 판정/시계열 비교 4종 데이터셋.
실제 키움 계정 접속·주문 또는 사용자 Windows PC 실측은 수행하지 않았습니다.
첫 조회는 API 통신 시간이 필요하며, 저장된 결과는 표시된 조회 시각의 자료입니다.
