PUMA STOCK PRO v1.2.0

단타 5분봉 날짜 구분
- 단타 기준 분봉은 계속 5분봉으로 고정
- 통합 트레이딩 5분봉 화면에 거래일 선택 드롭다운 추가
- 전체 보기에서는 거래일 경계마다 세로 점선과 MM/DD 라벨 표시
- 특정 거래일을 선택하면 해당 날짜 5분봉만 차트에 표시
- 전일 / 다음일 버튼으로 거래일 단위 이동
- 단타 상세 분석 화면에도 동일 날짜 선택/전일/다음일 기능 연동
- 메인과 단타 상세의 선택 날짜가 서로 동기화
- 날짜별 분석 시 이전 봉은 EMA/기준선 계산 컨텍스트로 유지하고 미래 날짜 데이터는 제거
- 과거 날짜 복기 시 일봉 거래량 비교에서도 선택일 이후 미래 일봉을 사용하지 않음
- 키움 5분봉 조회를 continuation 최대 4페이지까지 지원해 날짜 선택 범위를 확대
