PUMA STOCK PRO v1.8.0

매집봉 오탐 개선
- 단독 1회 조건충족 봉은 더 이상 '매집'으로 확정 표시하지 않음
- 고거래량 + 긴 윗꼬리 또는 장대음봉을 1차 '매집후보'로만 기록
- 긴 윗꼬리 조건 강화: 전체폭 비중 + 몸통 대비 우세 + 아래꼬리보다 명확히 긴 경우
- 장대음봉 조건 강화: 충분한 몸통 + 종가가 봉 하단부에 위치
- 후보가 20봉 이내에 2회 이상 반복되는 그룹만 '매집확정/매집구간'으로 판정
- 역매공파 점수에도 확정 매집만 반영
- 상세에는 확정 봉 수와 후보 봉 수를 구분해서 표시
- 차트 라벨도 '매집' 대신 '매집확정'으로 표시

하단 전략3종 분석
- 단타/역매공파/밥그릇3번 카드의 ... 말줄임 제거
- 마우스 오버 툴팁 제거
- 각 카드 자체에 세로 스크롤바 적용
- 단계/점수/유사구간확률/PUMA판단/이유 전체 문장을 카드 안에서 스크롤로 확인
- 저해상도에서도 카드 높이는 제한하고 내부 스크롤로 전체 내용을 볼 수 있게 변경
