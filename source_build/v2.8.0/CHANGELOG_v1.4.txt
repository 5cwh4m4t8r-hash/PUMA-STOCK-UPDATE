PUMA STOCK PRO v1.4.0

사용자 영웅문 차트 반영 1차
- 일봉/5분봉 차트에 일목균형표 선행스팬1·2 파란 구름대 추가
- 표준 선행스팬1: (전환선9 + 기준선26) / 2 를 26칸 선행
- 표준 선행스팬2: 52기간 최고/최저 중간값을 26칸 선행
- 최신 차트 오른쪽에 +26 미래영역을 확보해 구름대를 앞으로 표시
- 사용자가 보내준 영웅문 일봉/분봉 화면을 기준으로 파란 채움 표시

수박지표
- 기존 초록/빨강 단순 바는 수박지표로 인정하지 않고 화면에서 제거
- 실제 수박 수식/조건을 받기 전까지 수박 신호는 '사용자 수식 입력 대기'로 표시

UI/분석
- '고급 주문' 명칭을 '직접 주문'으로 변경
- 메인 단타/역매공파/밥그릇3번 분석 카드에 '이유:' 한 줄 추가
- 오른쪽 상세 분석에도 '간단 이유' 행 추가
- 단타: 기준선/EMA/거래량/돌파·눌림을 간단 이유로 요약
- 역매공파: 역배열/매집/공구리/상단안착/파란점선 상태를 요약
- 밥그릇3번: 224EMA 아래/돌파/안착/눌림 상태를 요약
