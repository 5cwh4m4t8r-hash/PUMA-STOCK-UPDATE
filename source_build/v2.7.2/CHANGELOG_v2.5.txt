PUMA STOCK PRO v2.5.0

응답없음/속도 수정
- 키움 종목정보, 5분봉, 일봉 REST 호출을 GUI 메인 스레드에서 분리
- REST 통신 중에도 창 이동/탭 전환/스크롤 등 UI 이벤트 처리 가능
- 별도 작업 스레드에서는 독립 requests.Session을 사용해 UI/조건검색 통신과 충돌 최소화
- 연속 클릭 시 로딩 작업을 무한 중첩하지 않고 현재 요청 종료 후 최신 요청만 이어서 처리
- 같은 종목/같은 페이지 데이터는 8초간 재사용
- 통합트레이딩에서 이미 받은 5분봉/일봉을 단타분석 탭에서 다시 REST 호출하지 않고 재사용

박스권/돌파 분석 성능
- v2.2~v2.4의 핵심 병목 수정
- 이전: 거의 모든 봉마다 10~160봉 이상의 여러 박스 후보를 정렬/검사한 뒤 거래량을 확인
- v2.5: 먼저 거래량강도 300% 후보를 싸게 검사하고, 후보봉에서만 무거운 박스/전고점 탐색 실행
- 동일 end_idx 구조 탐색은 한 분석 안에서 캐시
- 동일 캔들+동일 설정의 공통경로 결과는 최대 32개 LRU형 캐시로 재사용
- 스윙 분석기가 이미 계산한 core_path/path_breakout/path_pullback/path_rebreakout은 UI가 다시 계산하지 않음

정확도
- 공구리, 돌파, 눌림, 재돌파의 v2.3 기준 자체는 유지
- 속도를 위해 판단 기준을 낮추지 않음
- 확률/수박/화살표 표시 로직 유지
