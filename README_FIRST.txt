PUMA STOCK PRO v2.9.4 CLEAN - 완전체

이 압축파일은 이전 PUMA 파일이 하나도 없어도 되는 전체 설치본입니다.
업데이트 패치가 아닙니다.

1. 압축을 원하는 폴더에 완전히 풉니다.
2. SETUP_CLEAN.bat 를 한 번 실행합니다.
3. 설치가 끝나면 START_PUMA.bat 를 실행합니다.

필수:
- Windows 10/11
- Python 3.11 또는 3.12 권장
- 인터넷 연결
- 키움 REST API 사용 환경

보안:
- EXE 없음
- VBS 없음
- PowerShell 없음
- 자동 자기수정 업데이트 없음
- 숨김/분리 프로세스 실행 없음
